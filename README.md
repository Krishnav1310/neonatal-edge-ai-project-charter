# AI-Based Neonatal Monitoring System – NAVAAYU

## Overview
This repository contains the Project Charter, system architecture, and complete codebase for the AI-Based Neonatal Monitoring System. 

## Repository Structure
* **`/Project_Overview`**: Contains all core research, timelines, and architectural documentation.
* **`/Backend`**: FastAPI backend setup and API logic.
* **`/Frontend`**: React Dashboard setup for the user interface.
* **`/ML_Model_Implementation`**: Core machine learning models and training scripts.
* **`/ML_WORKFLOW`**: Data pipelines and model workflow documentation.
* **`/deployment`**: API endpoints and deployment configurations.
