# Day 5 - Machine Learning Model Implementation

## Overview

This module contains the first implementation of the neonatal health prediction model.

The workflow includes:

- Dataset loading
- Data preprocessing
- Feature selection
- Train-test split
- Random Forest model training
- Prediction
- Model evaluation

## Model

Random Forest Classifier

## Input Features

- Heart Rate
- SpO₂
- Respiratory Rate
- Temperature

## Output Classes

- Safe
- Warning
- Critical

## Evaluation Metrics

- Accuracy
- Classification Report
- Confusion Matrix

The trained model will later be integrated with the FastAPI backend for real-time neonatal monitoring.
