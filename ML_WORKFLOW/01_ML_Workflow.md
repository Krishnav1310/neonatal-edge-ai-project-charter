# Machine Learning Workflow

The NAVAAYU AI model follows these stages:

1. Receive neonatal vital signs.
2. Validate incoming data.
3. Preprocess the data.
4. Select relevant features.
5. Feed the processed data into the Random Forest model.
6. Predict the neonatal health status.
7. Generate a risk score.
8. Send prediction results to the dashboard.

Current Model:
Random Forest Classifier
